# cedarview

- The listing site's look, voice and photo order are set in `site/STYLE.md`, and every fact lives in `site/data/site.json`. These override the defaults of any design skill (`impeccable`, `motion`, or skills installed elsewhere): use the skills for craft and review, not to change the palette, voice or claims.
- Run `npm run check` in `site/` after editing listing content.
